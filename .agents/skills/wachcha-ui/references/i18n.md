# Multilingual i18n (`EN` / `RU` / `TR`)

## Files

- `src/lib/i18n.ts`: `@preact/signals` reactive `locale` signal (`'en' | 'ru' | 'tr'`), `setLocale()`, `detectLocale()`, and `t(key, params?)`.
- `src/locales/en.ts`: Canonical source of truth defining the `TranslationKey` union type.
- `src/locales/ru.ts` & `src/locales/tr.ts`: Typed as `Record<TranslationKey, string>` so **TypeScript compile (`tsc -b`) fails immediately** if any key is missing in Russian or Turkish!

## Conventions

- Auto-detect locale from `navigator.languages` on first launch (`ru*` → `ru`, `tr*` → `tr`, else `en`), persisted in `localStorage` under `wachcha:locale`.
- Update `document.documentElement.lang` whenever `locale` changes so font shaping and screen readers stay accurate.
- Interpolate dynamic values with `{param}` syntax (e.g. `t('player.skipIn', { seconds: 4 })`).
- Pass active `locale` to backend catalog/detail requests so TMDB, Shikimori, and TVMaze prefer localized titles & synopses.
