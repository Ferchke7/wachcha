# Wachcha GLSL Upscaling Shaders

Optional LGPL/MIT GLSL shader presets loaded by `libmpv` when selected in **Settings → Playback Engine**:

- `Anime4K_Upscale_CNN_x2_S.glsl` — Fast anime line-art upscaling (`anime4k-fast`)
- `FSR.glsl` — AMD FidelityFX Super Resolution live-action sharpening (`fsr`)
- `FSRCNNX_x2_8-0-4-1.glsl` — High-detail neural x2 upscaling (`fsrcnnx`)

Place compatible shader files here when building desktop bundles with GLSL upscaling enabled.
